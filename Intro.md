This presentation explores a covert data exfiltration technique where image or file content is fragmented into small byte ranges and transmitted asynchronously via HTTP. These fragments, often overlooked in traditional monitoring systems, can bypass Data Loss Prevention (DLP) tools. By analyzing PCAP files, we uncover how HTTP Content-Range headers are used for partial data transfer, making reconstruction difficult without deep packet reassembly. The session introduces FlowStitch, a custom Python tool that detects, sequences, and reconstructs such fragmented payloads from captured packets, revealing hidden content like images or messages. The presentation includes real-world PCAP analysis, threat modeling, architecture flow, and a demonstration of how this method can be leveraged in both attack and defense scenarios.
